# IRP Web Development Assignment

## Project structure
- `part-a-responsive-ui/index.html` — semantic IRP LMS Home Page
- `part-a-responsive-ui/style.css` — responsive CSS
- `part-b-javascript/bank.js` — Types & Coercion, Scoping & Hoisting
- `README.md` — setup and testing instructions

## Part A
Open `part-a-responsive-ui/index.html` in Chrome. Scroll to verify the sticky navigation. Use Developer Tools (F12) and Device Toolbar to test desktop (1200px+) and mobile (375px/390px). Desktop shows five learning cards in one row; mobile shows one column without horizontal overflow.

## Part B
From the repository root, run:
```bash
node part-b-javascript/bank.js
```
The script runs the parseAmount test cases and the required hoisting and asynchronous-loop demonstrations.

Create a public GitHub repository, push this exact project structure, and verify its public access in a private/incognito browser window. Submit the public repository URL.
